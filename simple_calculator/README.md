Simple Calculator V.0.0.1

Compile command :
"gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator"

Instructions :
Once the compiled C file is executed, the user will be greeted by a menu in which different arithmetic operations are proposed.
Simply enter in the input the number of the specific operation (1 - Additions, 2 - Substractions, 3 - Multiplications, 4 - Divisions) or 0 to exit the program.

Supported operations :
This program can support the four basic arithmetic operations: additions, substractions, multiplications and divisions.
